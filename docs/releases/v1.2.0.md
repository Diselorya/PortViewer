# PortViewer v1.2.0

本版补齐端口列表的字段、筛选与分组，并将 GitHub 发布、远端同步和本地安装包更新纳入同一个发布命令。

## 更新内容

- 监听地址与端口号各占一列，方向/角色独立显示和排序；远端地址与端口也分别展示。
- 新增“上级服务”字段，区分 Docker、systemd、Windows 服务、NSSM、IIS 和 Nginx；具体服务、容器或项目的名称、用途及路径继续显示在归属信息中。没有足够证据时标记为“未识别”。
- 支持协议、IP 版本、监听/远端地址和端口、方向/角色、状态、上级服务、进程状态、归属类型与可信度的组合多选筛选。
- 支持按任一可筛选字段分组，显示组名与数量，保留组内排序、选择和导出；分组视图使用分页，未分组继续使用虚拟滚动。
- 服务归属不完整、访问受限和 Docker 超时等动态提示移到列表底部的固定区域，查看详情时保持列表位置稳定。
- Windows/Linux 后端、JSON API、CLI、MCP 和 CSV/JSON 导出同步包含上级服务信息；旧设置自动迁移。
- 新增一键发布与恢复命令：精确源码 CI 全绿后构建并校验安装包，发布 GitHub Release、同步配置的全部远端和版本标签，并更新本地 `release` 根目录及版本目录。版本或 SHA-256 不一致时停止，避免遗漏或混入旧包。

## 下载

| 文件 | 用途 |
|---|---|
| `PortViewer-windows-x64-setup.exe` | Windows 10/11 x64 在线安装包，缺少 WebView2 时下载官方 Runtime |
| `PortViewer-windows-x64-offline.msi` | Windows x64 离线安装包，包含完整 WebView2 Runtime |
| `PortViewer-WebGUI-windows-x64.zip` | Windows x64 WebGUI、HTTP API、CLI 和 MCP 服务 |
| `PortViewer-WebGUI-linux-x64.tar.gz` | Ubuntu/Linux x64 WebGUI，含启动脚本、部署指南及 systemd 模板 |
| `SHA256SUMS-windows.txt` / `SHA256SUMS-linux.txt` | 对应平台发行包的 SHA-256 校验值 |

Linux 解压后运行 `./start.sh`，浏览器打开 `http://127.0.0.1:17890`。Windows WebGUI 解压后运行 `./portviewer-web.exe serve --assets ./web-assets`。

## 升级说明

Windows 安装包仍未签名，安装前可用随包清单核对 SHA-256。安装依赖说明见 `docs/installation.md`。

受限进程或容器信息需要相应系统权限。未识别到上级服务不表示进程一定没有受管理；详细归属仍以当前扫描证据为准。

发布流程的使用、远端映射与失败恢复见 `docs/releasing.md`。
