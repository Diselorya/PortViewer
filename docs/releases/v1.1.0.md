# PortViewer v1.1.0

本版补齐 Ubuntu 部署修复和端口业务归属：从端口号继续找到具体容器、服务、项目、用途及路径。

## 更新内容

- Linux Docker 归属展示容器名称、镜像、Compose 项目与服务、可用的描述和挂载路径；按协议、监听地址和端口匹配 published port。
- systemd 归属展示实际 unit 名称、服务描述、配置文件及工作目录，减少只显示 `systemd` 的无效信息。
- Node.js/Python 归属展示项目名与简介、入口、运行模式、项目目录及虚拟环境等路径；已知系统程序附用途说明。
- 主列表、详情、字段搜索、复制、CSV/JSON 导出以及 CLI/MCP 输出同步展示归属信息和证据来源。
- 修复 Ubuntu systemd 沙箱中 health 正常但端口扫描返回 500 的问题；随包提供包含 `AF_NETLINK` 的默认服务模板及可选完整归因配置。
- 支持代理剥离前缀的 `/portviewer/` 子路径部署，修复资源与 API 的相对地址。
- 升级 `quinn-proto` 至 0.11.18，修复三项 RustSec 漏洞公告。

## 下载

| 文件 | 用途 |
|---|---|
| `PortViewer-windows-x64-setup.exe` | Windows 10/11 x64 在线安装包；缺少 WebView2 时下载官方 Runtime |
| `PortViewer-windows-x64-offline.msi` | Windows x64 离线安装包；包含完整 WebView2 Runtime，体积较大 |
| `PortViewer-WebGUI-windows-x64.zip` | Windows x64 只读 WebGUI、HTTP API、CLI 和 MCP 服务 |
| `PortViewer-WebGUI-linux-x64.tar.gz` | Linux x64 WebGUI，使用 Ubuntu 24.04 构建；含启动脚本、部署指南和 systemd 模板 |
| `SHA256SUMS-windows.txt` / `SHA256SUMS-linux.txt` | 对应平台下载文件的 SHA-256 校验值 |

Linux 解压后运行 `./start.sh`，浏览器打开 `http://127.0.0.1:17890`。Windows WebGUI 解压后运行 `./portviewer-web.exe serve --assets ./web-assets`。压缩包内的 `docs/webgui-deployment.md` 包含 systemd、NSSM 和反向代理部署方法，`docs/lan-port-api.md` 包含 API、CLI 和 MCP 使用说明。

## 权限与兼容性

Linux 普通账号对其他用户的进程可能只显示未知归属。完整归因通常需要 root，以及可读的 `/proc` 和本机 Docker socket；随包的 `deploy/linux/portviewer-web-full-attribution.conf` 为显式启用选项。项目简介依赖本地元数据，缺失或无权读取时会明确标注，不会推测具体业务。

Windows 安装包未使用 Authenticode 证书签名，与上一版一致。安装前请核对 SHA-256；安装和 WebView2 依赖说明见包内或仓库的 `docs/installation.md`。
