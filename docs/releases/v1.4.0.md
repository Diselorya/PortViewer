# PortViewer v1.4.0

本版完善全量列表、条件切换、表头拖拽、视图自动保存和详情访问入口。

## 更新内容

- 筛选与着色共用条件逻辑：字段之间可选全部满足/满足任一，字段内可选包含任一/包含全部；旧设置默认语义保持一致。
- 取消主表、分组、筛选候选和详情关联连接的分页，移除最大显示条数限制；完整扫描数据一次可用，虚拟滚动控制界面节点数量。
- 仅正在排序的字段显示单向升序或降序箭头，多字段排序和列头操作保持一致。
- 默认字段顺序调整为服务中文名、进程名、归属类型、归属名称、状态、协议类型、监听地址、本地端口号、方向、对端机器名、对端地址、对端端口号、服务描述。其余字段仍可在字段面板开启。
- 表头可拖拽调整顺序，与字段面板联动，隐藏字段保留在配置中。
- 中文对照表扩充至 64 项。优先保留真实中文名，未知项使用中文类别与原始名称，原始项目身份和候选状态保持。
- 视图设置升级至 schema 5，自动保存搜索、筛选及条件模式、分组及展开状态、排序、列顺序/宽度/可见性、密度和着色；旧版默认布局升级，自定义布局保留。
- 点击详情外遮罩即可关闭；详情内点击和拖选继续保留。
- 详情的 IP+端口文字可直接打开浏览器，未知 TCP 明确标记为尝试 HTTP，并保留尝试 HTTPS；端点协议和地址边界仍经过验证。
