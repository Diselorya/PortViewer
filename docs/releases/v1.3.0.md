# PortViewer v1.3.0

本版把端口列表改为以服务名称和用途为阅读入口的紧凑工作台，补齐服务资料、访问入口、机器详情及视图配置。

## 更新内容

- 服务中文名和描述优先显示，维护随包版本化中文对照表，保留真实容器、unit、服务和项目标识。
- 本机服务描述优先使用当前配置和项目元数据；公开软件说明与实际项目用途分开展示，并保留来源、匹配状态和更新时间。
- 默认异步补充公开 GitHub、npm 和 PyPI 资料，按身份去重、缓存和限流，支持受限的本机代理，并对临时请求失败限定重试；同名仓库作为候选，断网不影响基础端口扫描。
- AI 整理为可选功能，通过后端环境配置，界面显示可用状态；只处理公开软件片段，不把本机路径、参数或私有项目简介发送给 AI。
- 端口可打开有依据的 HTTP(S) 地址，其他协议进入端口详情；LAN WebGUI、loopback 和 IPv6 地址分别处理。
- 服务名、本机和对端可打开覆盖式详情抽屉，集中查看用途、运行方式、证据与路径、资料来源和相关连接。对端名称标注反向 DNS 来源。
- 筛选、分组、多字段排序、着色和字段配置统一为浮动面板，保留表格位置与选择；字段顺序真实生效。
- 默认紧凑显示，列宽按有限样本自动计算，后台补充资料时不改变行高或已分配列宽。
- 状态标签使用不同语义颜色；条件着色支持整行或指定列的匹配单元格，复用简单筛选条件并按优先级生效。
- 旧设置迁移至 schema 4；搜索、排序和导出复用展示数据，旧快照保持兼容。
- 发布流程为微软 Runtime 的临时下载连接故障加入最多三次重试，版本与 SHA-256 门禁保持不变。
